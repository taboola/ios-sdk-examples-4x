# ios-sdk-examples-4x

Latest iOS SDK Version: 4.3.1

Taboola SDK allows publisher to display Taboola's Widgets and Feed within their iOS apps

## Getting Started
To get started with the Taboola iOS SDK, please follow this link [iOS SDK documentation](https://developers.taboola.com/taboolasdk/v4/docs/welcome).

## Running the examples
The examples add the SDK with Swift Package Manager, from [taboola-spm-ios-sdk](https://github.com/taboola/taboola-spm-ios-sdk) (`TaboolaSDK`, up to the next major version from 4.3.1). No CocoaPods install is needed:

1. Open the example's `.xcodeproj` (for example `TaboolaSDKExampleSwift/TaboolaSDKExampleSwift.xcodeproj`).
2. Xcode resolves the package on first open. To pick up a newer SDK release, use **File > Packages > Update to Latest Package Versions**.
3. Build and run the app's scheme.

To add the SDK to your own app the same way, use **File > Add Package Dependencies…** with `https://github.com/taboola/taboola-spm-ios-sdk` and add the `TaboolaSDK` product to your app target.
